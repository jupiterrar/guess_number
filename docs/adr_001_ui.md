# ADR-001: Разделение Game и UI

## Контекст
Процедурный код смешивал логику и ввод/вывод.

## Решение
Выделен класс UI, передаётся через конструктор (DI).

## Альтернативы
1. Глобальный UI-модуль
2. Наследование
3. Инъекция через конструктор (выбрано)

## Последствия
- Логика тестируется через Mock
- Легко заменить UI
