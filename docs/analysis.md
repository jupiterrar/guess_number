# Анализ процедурного кода

## Исходный процедурный код

```python
# Исходный процедурный код (только для чтения и анализа — не запускаем input)
import random


def play_guess_number_procedural():
    secret = random.randint(1, 100)
    attempts = 0
    max_attempts = 10
    print("Я загадал число от 1 до 100. У вас 10 попыток.")
    while attempts < max_attempts:
        try:
            guess = int(input("Ваш вариант: "))
        except ValueError:
            print("Введите число!")
            continue
        attempts += 1
        if guess < secret:
            print("Больше!")
        elif guess > secret:
            print("Меньше!")
        else:
            print(f"Угадали! Попыток: {attempts}")
            return
    print(f"Попытки закончились. Было загадано: {secret}")
```

## 1.1. Таблица анализа

| Что | Где в исходном коде | Куда перенести |
|-----|---------------------|----------------|
| Секретное число | `secret = random.randint(1, 100)` | Атрибут `Game()` |
| Лимит попыток | `max_attempts = 10` | Атрибут `Game()` |
| Номер попытки | `attempts = 0` | Атрибут `Player()` |
| Ввод игрока | `input("Ваш вариант: ")` | Метод `Player()` |
| Проверка ввода | `try/except ValueError` | Метод `Player()` |
| Сравнение с секретом | `if guess < secret ...` | Метод `Game()` |
| Генерация числа | `random.randint(1, 100)` | Метод `Game()` |
| Подсказка | `print("Больше!")` и т.д. | Метод `Game()` |
| Вывод сообщений | `print(...)` | Метод `UI()` |
| Ввод | `input(...)` | Метод `UI()` |

## 1.2. Ответы письменно

### 1. Какие классы вы выделите? Обоснуйте.

Классы `Game()`, `Player()`, `UI()`.
`Game()` - состояние игры и логика
`Player()` - данные игрока (счетчик попыток)
`UI()` - ввод и вывод

### 2. Какие атрибуты будут приватными?

- `self.__secret` - чтобы нельзя было изменить секретное число
- `self.__max_attempts` - чтобы нельзя было изменить лимит попыток
- `self.__ui` - чтобы нельзя было изменить зависимость извне
- `self.__attempts` - чтобы нельзя было изменить счётчик попыток

### 3. Какие методы будут публичными?

- `game.run()` - чтобы игру можно было запустить
- `game.check_guess()` - дать подсказку для попытки
- `player.make_guess()` - запросить у игрока число
- `ui.show_message()` - вывод
- `ui.get_input()` - ввод

### 4. Есть ли в исходном коде «God Object»?

Да, есть: функция `play_guess_number_procedural()`. 
В ней хранится все: генерация числа, игровой цикл, обработка ввода, обработка ошибок, проверка попыток и вывод сообщений. 
Функция делает всё сразу - это классический признак божественного объекта
